# 🚪 IoT One-Pass Smart Gate (ระบบขออนุญาตออกนอกสถานศึกษาครบจบด้วย QR Code)

ระบบขออนุญาตออกนอกสถานศึกษาอัจฉริยะแบบครบวงจร ผ่านการอนุมัติ 3 ขั้นตอน (ครูที่ปรึกษา ➔ หัวหน้าแผนก ➔ งานปกครอง) และออก QR Code สำหรับสแกนเปิดประตูตู้ IoT อัตโนมัติ

---

## 📂 โครงสร้างโปรเจกต์

```text
smart-gate/
├── database/
│   └── schema.sql                  ← โครงสร้างฐานข้อมูล Supabase (PostgreSQL) พร้อม Seed Data
├── firmware/
│   └── smart_gate_esp32/
│       ├── smart_gate_esp32.ino    ← โค้ด Arduino ESP32 (MQTT, OLED, Relay, Servo, Ultrasonic)
│       └── secrets.example.h       ← ตัวอย่างไฟล์ตั้งค่า Wi-Fi และ HiveMQ MQTT
├── public/
│   ├── index.html                  ← หน้าเว็บหลัก UI สวยงาม รองรับทุกบทบาท + ตู้ Kiosk + Virtual Hardware
│   └── app.js                      ← ระบบควบคุม Frontend, กล้องสแกน QR, สลับบทบาท, Polling สถานะบอร์ด
├── server.js                       ← Node.js Express Backend API + MQTT Publisher
├── package.json                    ← แพ็กเกจระบบ
├── vercel.json                     ← ไฟล์สำหรับ Deploy ขึ้น Vercel ฟรีด้วย 1 คลิก
└── README.md
```

---

## 🚀 วิธีเปิดใช้งานบนเครื่องคอมพิวเตอร์ (Local Test)

1. เปิด Terminal ในโฟลเดอร์ `smart-gate`
2. รันคำสั่งเริ่มระบบ:
   ```bash
   npm start
   ```
3. เปิดเบราว์เซอร์ไปที่: **`http://localhost:3000`**

## 🌟 ฟังก์ชันเด่นที่สร้างเสร็จแล้ว

1. **สลับบทบาทได้ทันทีด้วยแถบด้านบน (Quick Role Switcher):**
   - 👨‍🎓 **นักเรียน (สมชาย / สมศรี):** ยื่นขออนุญาต, ดูสถานะแบบเรียลไทม์ 3 ขั้นตอน, และกดเปิดดู **QR Code ประตู** เมื่ออนุมัติสมบูรณ์
   - 👨‍🏫 **ครูที่ปรึกษา (อ.สมคิด):** อนุมัติขั้นที่ 1 (เห็นเฉพาะนักเรียนในห้องที่ตนเองเป็นที่ปรึกษา)
   - 👔 **หัวหน้าแผนกวิชา (อ.ดร.ประเสริฐ):** อนุมัติขั้นที่ 2 (เห็นคำขอที่ผ่านครูที่ปรึกษามาแล้ว)
   - 👮‍♂️ **หัวหน้างานปกครอง (อ.อำนาจ):** อนุมัติขั้นที่ 3 ขั้นสุดท้าย (เมื่อกดอนุมัติ ระบบจะสร้าง QR Token ป้องกันการปลอมแปลงทันที)
   - 🚪 **ตู้สแกน Kiosk (หน้าประตู):** เปิดกล้อง Webcam ผ่านเบราว์เซอร์ สแกน QR จริงได้ทันที พร้อมหน้าจอแจ้งเตือนว่าผ่านหรือไม่ผ่าน

2. **📟 บอร์ดจำลอง IoT Hardware Simulator (ด้านขวาของจอ):**
   - จอ **OLED 0.96"** เสมือนจริง แสดงข้อความ `>> OPEN <<` / `== CLOSED ==`
   - ไฟ **LED เขียว / แดง** เปลี่ยนสถานะตามการสแกนจริง
   - กลอนประตู **Relay / Servo** แสดงสถานะการปลดล็อก
   - ปุ่ม **ทดสอบเปิดประตูฉุกเฉิน (5 วินาที)**

3. **🔒 ระบบความปลอดภัย QR Code:**
   - ใช้ Token สุ่ม UUID
   - **ใช้สแกนออกได้เพียงครั้งเดียว (Single-use)** ป้องกันการแคปจอส่งให้เพื่อน
   - ตรวจสอบความถูกต้องและบันทึกประวัติการสแกน (Scan Logs) แบบเรียลไทม์

## ☁️ การเชื่อมต่อ Cloud ฟรี (เมื่อต้องการ Deploy)

1. **Supabase (Database):**
   - นำโค้ดจาก `database/schema.sql` ไปวางในเมนู **SQL Editor** บนเว็บ Supabase แล้วกด Run
2. **HiveMQ Cloud (MQTT Broker สำหรับสั่งบอร์ดข้ามอินเทอร์เน็ต):**
   - ใส่ URL, User, Password ลงใน `.env` และในไฟล์ `firmware/.../secrets.h`
3. **Vercel (Web Hosting):**
   - เชื่อมต่อ GitHub repo นี้กับ Vercel เพื่อให้เว็บออนไลน์ 24 ชม. ได้ฟรี
