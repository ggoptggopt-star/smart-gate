# OnePass - ระบบขออนุญาตออกนอกสถานศึกษา ด้วยระบบ QR Code

เว็บแอปพลิเคชันระบบขออนุญาตออกนอกสถานศึกษา พัฒนาด้วย **Node.js (Backend) + Vanilla JavaScript (Frontend) ธรรมดา โดยไม่มีการใช้ PHP** เชื่อมต่อกับฐานข้อมูล **MySQL ของ XAMPP (`ongkharak_std`)**

---

## 📋 ข้อกำหนดตามความต้องการของระบบ

1. **การเข้าสู่ระบบ (Authentication) & บังคับเปลี่ยนรหัสผ่านครั้งแรก**:
   - ทุกบทบาทเข้าใช้งานด้วย **รหัสประจำตัว** และใช้รหัสผ่านเริ่มต้น **`123456`**
   - เมื่อเข้าสู่ระบบครั้งแรก ระบบจะตรวจพบสถานะและ **บังคับเปลี่ยนรหัสผ่านใหม่ทันที** (ความยาวอย่างน้อย 6 ตัวอักษร และต้องไม่ซ้ำกับ `123456`)
   - เมื่อเปลี่ยนรหัสผ่านสำเร็จ ระบบจะเข้ารหัสด้วย bcrypt และอัปเดตลงฐานข้อมูล MySQL อัตโนมัติ

2. **บทบาทและสายการพิจารณาอนุมัติ 5 ระดับ (5-Tier Approval)**:
   - 🎓 **ผู้เรียน (Student)**: ยื่นคำขอ ระบุวัน เวลา เหตุผล ประเภท (ออกชั่วคราว/ออกแล้วไม่กลับ) และเลือกครูรายวิชาในคาบ
   - 📚 **ครูรายวิชา (Subject Teacher)**: พิจารณาอนุมัติเป็นลำดับที่ 1
   - 🧑‍🏫 **ครูที่ปรึกษา (Advisor)**: ดึงข้อมูลอัตโนมัติตามชั้น/แผนกจากตาราง `advisor_assignments` พิจารณาอนุมัติเป็นลำดับที่ 2
   - 🏢 **หัวหน้าแผนก (Head of Department)**: ดึงข้อมูลอัตโนมัติจากตาราง `majors` พิจารณาอนุมัติเป็นลำดับที่ 3
   - ⚖️ **หัวหน้างานปกครอง (Head of Discipline)**: ดึงข้อมูลอัตโนมัติจากตาราง `gate_duty_assignments` พิจารณาอนุมัติเป็นลำดับที่ 4
   - 🏛️ **รองผู้อำนวยการฝ่ายกิจการนักเรียน นักศึกษา**: พิจารณาอนุมัติเป็นลำดับที่ 5 (อนุมัติสมบูรณ์)

3. **ระบบ QR Code & บัตรผ่านดิจิทัล (Digital Gate Pass)**:
   - เมื่อได้รับการอนุมัติครบสาย ระบบจะสร้างรหัส QR Code Token แบบ Unique ทันที
   - นักเรียนสามารถเปิดดู "บัตรอนุญาตออกนอกสถานศึกษา (OnePass)" พร้อม QR Code บนหน้าจอมือถือ
   - เจ้าหน้าที่เวรประตู / รปภ. สามารถเปิดหน้า "ตรวจบัตรผ่าน" สแกน QR Code หรือกรอกรหัส Token เพื่อตรวจสอบความถูกต้อง และกดปุ่ม:
     - **บันทึกเวลาออกจากสถานศึกษา (Check-Out)**
     - **บันทึกเวลากลับเข้าสถานศึกษา (Check-In)**

## 🗄️ การติดตั้งฐานข้อมูล (MySQL บน XAMPP)

1. เปิดโปรแกรม **XAMPP Control Panel** แล้วกด **Start** ที่โมดูล **MySQL**
2. เปิดเบราว์เซอร์ไปที่ **phpMyAdmin** (`http://localhost/phpmyadmin`)
3. สร้างฐานข้อมูลชื่อ: `ongkharak_std` (Collation: `utf8mb4_unicode_ci` หรือ `utf8mb4_general_ci`)
4. นำเข้าไฟล์ SQL:
   - กดเมนู **Import** แล้วเลือกไฟล์ `database/ongkharak_std.sql`
   - จากนั้น Import ไฟล์ `database/onepass_schema.sql` (หรือระบบ Node.js จะช่วยตรวจสอบและสร้างตาราง OnePass ให้อัตโนมัติเมื่อเปิดเซิร์ฟเวอร์)
   - *(ตัวเลือกเสริม)*: หากต้องการรีเซ็ตรหัสผ่านทุก User ในระบบให้กลับเป็น `123456` เพื่อทดสอบ ให้รันคำสั่งในไฟล์ `database/seed_passwords.sql`

## 📁 โครงสร้างไฟล์ในโครงการ

```text
Onepass2/
├── package.json              # กำหนด dependencies (Express, mysql2, bcryptjs, qrcode, cors)
├── db.js                     # การเชื่อมต่อ MySQL XAMPP และ Auto-create Tables
├── server.js                 # Node.js Express REST API (Auth, Student, Requests, Approval, Gate)
├── public/                   # โฟลเดอร์หน้าบ้าน (Vanilla JS ธรรมดา ไม่ใช้ PHP)

│   ├── app.js                # โค้ดดิ้ง JavaScript หน้าบ้านทั้งหมด (State, Fetch, DOM, Events)
│   └── style.css             # การจัดรูปแบบตาราง ปุ่ม และโมดอล (เน้นความชัดเจนของโค้ด)
└── database/
    ├── ongkharak_std.sql     # ข้อมูลโรงเรียนเดิมที่แนบมา
    ├── onepass_schema.sql    # ตาราง onepass_requests และ onepass_logs
    └── seed_passwords.sql    # สคริปต์สำหรับรีเซ็ตรหัสผ่านเป็น 123456
```
